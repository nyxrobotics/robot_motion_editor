# 📘 ロボットモーション作成ノード：改良版仕様書

## 1. 目的と概要
このROS1ノードは、GUI上でロボットの関節動作を作成・編集・保存・再生する統合ツールである。  
Simulink風の状態遷移形式による視覚的な操作で、実機およびGazeboでの動作確認が可能。  
関節角度、PID、IMUによるフィードバック制御もサポートする。

---

## 2. GUI共通構成（`main_window.py`）
- モーション保存ディレクトリ入力（Browse可能）
- 「Use Real Robot」チェックボックス（Gazeboと切替）
- COMポート選択（自動検出 + 更新ボタン）
- ボーレート選択（4500000 ～ 9600 + 手入力可）
- 「Torque ON」チェックボックス
- 「初期姿勢に移動」ボタン（現在姿勢→初期姿勢に3秒で遷移）

---

## 3. 初期姿勢編集タブ（`initial_pose_editor.py`）
### 機能
- `robot_description` の transmission 定義からジョイント一覧を取得
- 各ジョイントに対して以下を設定：
  - スライダー + 数値入力（degree）
  - Enable チェックボックス
  - PID設定（PIDボタン）
  - フィードバック式（FBボタン、式はPython構文）

### 保存ファイル形式： `<motion_dir>/initial_pose.yaml`
```yaml
joints:
  head_joint_1:
    enable: true
    feedback: ''
    pid:
    - 0.0
    - 0.0
    - 0.0
    position: 0.0
  head_joint_2:
    enable: true
    feedback: ''
    pid:
    - 0.0
    - 0.0
    - 0.0
    position: 0.0
```

## 4. モーション作成タブ（`animation_widget.py`）

### 4.1 GUI構成
- 中央：編集シーン（`animation_editor_widget.py`）
- 左：アニメーション一覧（`animation_file_widget.py`）
- ダブルクリックで各要素を編集可能

### 4.2 構成要素（`animation_editor_widget.py`）

#### 4.2.1 ブロック

##### a. フレームブロック（`FrameBlockItem`）
- ラベル付き矩形（ダーク背景＋白文字、太枠）
- ドラッグで移動、右クリックで編集メニュー表示
- 出力：最大1本、入力：制限なし

##### b. 条件分岐ブロック
- **IfBlockItem**：Python式で True/False に分岐
  - 出力：2本、入力：制限なし
- **SwitchBlockItem**：整数式による複数分岐
  - 出力：制限なし、入力：制限なし

#### 4.2.2 接続要素：矢印（`ArrowItem`）
- 出力→入力方向を持つ
- hover時に中間点（hover_point）を表示
- 中間点クリックで waypoint を即時追加・ドラッグ可能
- waypoint を端点や他waypointに近づけると削除
- 接続状態に応じて：
  - 両端接続 → 実線
  - 片端のみ接続 → 点線
- waypoint 削除後は自動で直線補完

## 5. フレーム編集画面（`frame_editor.py`）
- 各ジョイントに対して：
  - 移動時間（move_duration）
  - 待機時間（wait_duration）
  - トルクON/OFF
  - PIDゲイン設定
  - フィードバック式（Python式）
  - 速度倍率（velocity_scale）

---

## 6. 数式入力の挙動（共通）
- 使用可能変数：
  - 他関節：`joint1` など
  - IMU：`imu_pitch`, `imu_acc_x` など

- 式に不備があれば：
  - 保存禁止
  - 赤色ハイライトで警告

- スライダーとの関係：
  - 数式あり：スライダーは薄色
  - 編集時、自動で `+定数` を付与することあり

## 7. アニメーションの保存と読み込み

### 7.1 ディレクトリ構成
```
<motion_dir>/<animation_name>/
├── animation.yaml            # 全体レイアウト・接続情報
├── offset.yaml               # 初期姿勢との差分
├── frames/
│   ├── pose0.yaml            # フレーム個別定義
│   └── pose2.yaml
├── conditions/
│   ├── if/
│   │   └── imu_if.yaml
│   └── switch/
│       └── button_switch.yaml
```

### 7.2 animation.yaml の例
```yaml
layout:
  block:
    frame_000_pose1:
      info:
        type: frame
        filename: pose1
        id: 0
      place:
        x: 100
        y: 100
      connection:
        output:
          out_0:
            target: frame_001_pose2
            ch: 0
            arrow: arrow_000
    frame_001_pose2:
      info:
        type: frame
        filename: pose2
        id: 1
      place:
        x: 300
        y: 300
      connection:
        output:
          out_0:
            target: ""
            ch: 0
            arrow: ""
  arrow:
    arrow_000:
      info:
        id: 0
      waypoints:
        - [200, 200]
```

### 7.3 offset.yaml
- `initial_pose.yaml` と同形式で各アニメーションの初期姿勢を設定
- `initial_pose.yaml` と差分がない場合、`initial_pose.yaml`の変更と同時に`initial_pose.yaml`と同じ内容で上書き

### 7.4 frame.yaml の例
```yaml
time:
  duration: 2.0
  wait: 1.0

velocity_scale:
  head_joint_1: 1.0
  head_joint_2: 1.0

joints:
  head_joint_1:
    enable: true
    feedback: ''
    pid:
      - 0.0
      - 0.0
      - 0.0
    position: 0.0
  head_joint_2:
    enable: true
    feedback: ''
    pid:
      - 0.0
      - 0.0
      - 0.0
    position: 0.0
```

### 7.5 if条件の例（`conditions/if/*.yaml`）
```yaml
expression: "def imu_norm = fabs(imu_gyro_x)"
condition: "imu_norm > 0.5"
```

### 7.6 switch条件の例（`conditions/switch/*.yaml`）
```yaml
expression: "mode = 2"
condition: "mode"
case:
  case_0:
    value: 0
  case_1:
    value: 1
  case_2:
    value: 2
  case_3:
    value: 3
```
